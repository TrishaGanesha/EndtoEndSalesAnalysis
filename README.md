## 📌 Project Overview

This project is an **End-to-End Sales Analysis** developed using **Python, SQL and Microsoft Power BI**.

The objective is to analyze sales performance across different **products, sales channels, states and regions**, while identifying revenue trends, profitability, seasonal patterns and potential business opportunities.

The project combines data cleaning, exploratory data analysis, SQL analysis and interactive Power BI visualization to transform raw sales data into meaningful business insights.

---

## 🎯 Business Problem

Businesses need to understand which products, channels and geographical regions contribute most to revenue and profit.

This project focuses on answering questions such as:

- What is the overall sales and profit performance?
- Which products generate the highest revenue?
- Which sales channels contribute the most?
- Which states and regions perform best?
- How does revenue change over time?
- Are there noticeable monthly or seasonal patterns?
- Where are the potential opportunities for improvement?

# 📂 Dataset

The dataset contains sales transaction information including:

- Order Number
- Order Date
- Customer Name
- Sales Channel
- Product
- Quantity
- Unit Price
- Revenue
- Cost
- State
- State Name
- US Region
- Budget

Additional calculated metrics were created during the analysis, including:

- Total Cost
- Profit
- Profit Margin %
- Order Month
- Order Month Number
